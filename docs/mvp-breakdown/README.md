# MVP 文档索引

## 文档

| 文件 | 用途 |
| --- | --- |
| `../PRD-MVP.md` | 当前已实现 MVP 的产品与接口规格，是 MVP 范围的事实来源 |
| `development-tasks.md` | 当前实现映射、测试缺口和后续产品任务 |
| `iteration-plan.md` | 已交付基线、建议下一迭代和风险登记 |

## 使用原则

1. 当前行为以代码和 `docs/PRD-MVP.md` 为准。
2. `docs/PRD.md` 描述更长期的产品方向，不等于当前实现承诺。
3. 音频、持久会话、PostgreSQL/pgvector 和本地模型均为后续候选。
4. 新能力进入开发前，先更新 PRD、API 契约和验收标准。
